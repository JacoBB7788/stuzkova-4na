# Stužková 4.NA

Appka triedy 4.NA na stužkovú (11. 12. 2026). Statická webová appka (PWA) na GitHub Pages; údaje sú v Google tabuľke za Google Apps Script API.

- `index.html` – celá appka
- `sw.js` – offline cache appky
- `manifest.webmanifest`, ikony – pridanie na plochu
- `apps-script/Code.gs` – kód Google Apps Script (API nad tabuľkou s dátami). Pri zmene: vložiť do Kód.gs, uložiť, Deploy → Manage deployments → New version.
